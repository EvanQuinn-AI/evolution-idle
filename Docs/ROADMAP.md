# Delivery Roadmap

## Phase 1 - Technical Prototype

- Package boundaries and composition root.
- Deterministic economy simulation and offline catch-up.
- Command/event/projection flow.
- CSV content compiler and sample catalog.
- Versioned save envelope, migration registry, backups, and recovery.
- Representative UI Toolkit runtime screen.
- Domain, persistence, content, and integration tests.
- CI validation and platform build definitions.

## Phase 2 - Vertical Slice

- Complete data-driven progression path and prestige reset.
- Production UI, localization, recovery UI, analytics queue, and sandbox IAP.
- Device performance instrumentation and budgets.
- Approve the creature visual DNA system and Fish-to-Wolf lineage slice before bulk asset production.
- Validate shared rig families, URP materials, LODs, Addressables, and mobile silhouette readability.

## Phase 3 - Alpha

- PlayFab guest identity and account linking.
- Cloud ancestry synchronization and conflict recovery.
- Achievements, accessibility, crash reporting, and complete build automation.
- Expand the approved creature families across the launch roster; do not introduce unreviewed bespoke art styles.

## Phase 4 - Beta

- Schema and feature freeze.
- Signed LiveOps catalogs and seasonal scheduling.
- Receipt validation, migration fuzzing, device optimization, and store compliance.

## Phase 5 - Launch

- Immutable release candidates and staged rollout.
- Steam, TestFlight, and Play release channels.
- Save-failure, crash, economy, rollback, and catalog-withdrawal monitoring.
